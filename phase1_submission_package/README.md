# Phase 1 Submission For SkyCoach Ai

This folder is a standalone submission bundle for the Phase 1 notebook.

## Included

- `Phase1_Submission_Notebook.ipynb`
- `PART1_WRITEUP.md`
- `REQUIREMENTS.txt`
- `data/datasets/` with the JSONL splits required by the notebook

## How to run

1. Open the notebook in VS Code or Jupyter.
2. Select a Python kernel with the packages from `REQUIREMENTS.txt` installed.
3. Run the notebook cells from top to bottom.

The notebook is written to locate the bundled `data/datasets` folder automatically.
